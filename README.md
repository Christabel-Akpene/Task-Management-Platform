# Task Manager

A simple Task Management web app built with React and TypeScript.

## Tech Stack
- React + TypeScript
- Tailwind CSS

## Cloning the Repository

1. Clone the repository
```bash
   git clone https://github.com/Christabel-Akpene/Task-Management-Platform.git
   cd Task-Management-Platform
```

2. Install dependencies
```bash
   npm install
```

3. Start the development server
```bash
   npm run dev
```

4. Open your browser with `http://localhost:5173`

## Features
- Add, edit, and delete tasks
- Change task status (Pending, In Progress, Completed)
- Filter tasks by status
